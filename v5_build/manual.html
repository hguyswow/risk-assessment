STEP 2-1. 🤖 AI 위험성평가 자동 생성 및 관리 (v5.5.21b 개편 및 UI 디자인 전면 고도화 ✨)

수동 선택이 번거롭다면, 화면 상단 우측 of [🤖 AI 생성] 버튼을 눌러 인공지능 안전 분석 시스템을 이용해 보고서를 자동으로 생성해 보세요.

1) 현장 정보 프리셋 템플릿 관리

  • 템플릿 저장 (v5.5.3 보완 🛠️): 기존의 '주요 작업 내용' 필드가 대분류 아래의 구체적인 공정 구역을 명시하는 하위 공종 *으로 성격이 명확해지고, 실제 현장에서 수행할 디테일한 작업 묘사를 적을 수 있는 주요 작업 내용 * 필수 입력란이 새롭게 분리 신설되었습니다. 현장 정보 입력 후 [💾 템플릿 저장] 버튼을 클릭해 이름을 지정해 등록하면, 자동으로 [공사종류] 하위공종 (예: [건축공사] 습식공사) 형태로 템플릿 명칭이 지능형 자동 추천 제안됩니다. (※ v5.5.3 버전에서는 템플릿 저장 모달 창이 AI 모달 최상단에 확실하게 뜨도록 쌓임 맥락을 통합했으며, Electron 환경에서 팝업이 뒤로 숨는 버그를 방지하기 위해 경고 alert() 창을 수려한 토스트 메시지로 전면 개선했습니다.)
  • 템플릿 불러오기: 다음 작업 시에는 드롭다운 목록에서 저장했던 프리셋을 선택하여 이전 현장 정보를 1초 만에 그대로 불러와 재활용할 수 있습니다.

2) 다중 API Key 저장 서랍 및 자동 롤오버(Failover)

  • AI 설정 탭 내부의 [🔑 API Key 저장 서랍] 버튼을 클릭하여 다수의 Gemini 또는 DeepSeek API Key들을 저장할 수 있습니다.
  • 무중단 롤오버: 등록된 여러 개의 API Key는 순차적으로 사용되며, 하나의 키가 일일 한도(Quota 429 Error)에 도달할 경우 대기 시간 없이 즉시 다음 API Key로 자동 전환(Failover)되어 대량의 위험성평가서도 끊김 없이 완성됩니다.
  • 로컬 LLM (LM Studio) 연동 (v5.5.1 신규 ✨): AI 프로바이더 목록에서 LM Studio (로컬 LLM)를 선택하면, 별도의 API Key 없이 로컬 호스트 엔드포인트(http://localhost:1234/v1)를 통해 오프라인 환경에서도 로컬 AI 모델을 이용해 무료 및 무제한으로 고속 자동 생성을 수행할 수 있습니다.
  • 생성 텍스트 글자수 세부 제한 (v5.5.2 신규 ✨): AI 설정 탭 하단에서 유해위험요인 최대 글자수 및 개선대책(감소대책) 최대 글자수를 직접 지정할 수 있습니다. (추천 수치: 유해위험요인 50자, 개선대책 100자 기본 제안) 이 수치 제한은 AI 프롬프트에 동적으로 연결되어 결과물의 텍스트 길이가 보고서 조판 가로 폭을 넘어가 양식이 흐트러지는 현상을 사전에 정교하게 예방해 줍니다.

3) 능동형 역질문 및 7단 양식 매핑

  • 사용자 추가 고려사항 (선택사항): 현장 정보 입력 탭에 추가 고려사항을 입력할 수 있어, 지하수위나 옹벽 등의 특이사항을 적어주시면 AI가 이를 우선 반영하여 아주 정교하고 밀착된 위험성평가서를 제안합니다.
  • 대화형 되묻기 및 객관식 문답 (v5.5.4 업그레이드 🚀): 사용자가 입력한 정보가 빈약할 때 작동하는 역질문 기능이 업그레이드되었습니다. [AI 재질문(Q&A) 활성화] 체크박스를 통해 기능을 켜거나 끌 수 있으며, 질문 수령 시 복수 선택이 가능한 체크박스형 객관식 문답과 자유 서술형 주관식 문답이 상황에 맞게 렌더링되어 빠르고 편리하게 고신뢰 답변을 수집합니다.
  • 최종 매핑: 완성된 안전 평가는 7단 정식 양식에 맞춰 자동으로 공종명과 안전 분류를 지능적으로 분석하여 편집 화면의 "🤖 AI 자동생성" 카테고리에 안전하게 자동 삽입됩니다.

🐳 DeepSeek API 설정 (강력 추천 🚀)

현재 자연어 성능 대비 압도적으로 저렴한 단가(Gemini 대비 약 1/10 비용)와 최상위 수준의 한국어 건설 안전 분석 능력을 보여주는 API 서비스입니다.

  • 1단계 (가입 및 API Key 발급): DeepSeek 개발자 플랫폼에 접속 및 가입한 뒤, [API Keys] 메뉴에서 [Create new api key]를 클릭하여 생성하고 복사합니다.
  • 2단계 (크레딧 충전/결제): [Top up] 또는 [Finance] 메뉴에서 최소 2$ ~ 5$ 정도의 선불 크레딧을 신용카드로 충전합니다. (한 번 충전 시 수백 장의 위험성평가서를 작성할 만큼 넉넉한 토큰량이 제공됩니다.)
  • 3단계 (프로그램 등록): 프로그램 내 AI 설정 탭에서 API 프로바이더를 DeepSeek로 선택한 뒤, 복사한 키를 붙여넣고 사용합니다.

♊ Google Gemini API 설정

기본적으로 빠른 속도와 한국어 문장력이 균형 잡혀 있는 범용 엔진입니다. 무료 기본 제공량(제한적)으로 테스트가 가능합니다.

  • 3단계 (프로그램 등록): 프로그램 내 AI 설정 탭에서 API 프로바이더를 Gemini로 선택하고 복사한 키를 붙여넣습니다.

인터넷망이 제공되지 않거나 사내 보안 규정상 현장 데이터를 외부 서버로 전송할 수 없을 때 최적입니다. 본인의 고성능 GPU(외장 그래픽카드)를 탑재한 PC 환경이 권장됩니다.

  • 1단계 (다운로드 및 설치): Ollama 공식 웹사이트에서 윈도우용 버전을 다운로드하여 설치 및 가동합니다.
  • 2단계 (인공지능 모델 다운로드): 명령 프롬프트(cmd) 또는 터미널을 열고 ollama run llama3 또는 ollama run gemma2 명령어를 실행하여 로컬 AI 모델 파일 다운로드를 완수합니다.
  • 3단계 (프로그램 연동): 다운로드 완료 시 백그라운드 서버(http://localhost:11434)가 자동 상시 대기하며, 프로그램 AI 설정 탭에서 Ollama를 고르면 별도의 API Key 없이 로컬 AI 생성이 동작합니다.

🎨 LM Studio 오프라인 로컬 LLM 설정 (시각적/무료 🔐)

시각적인 전용 GUI 앱을 통해 AI 모델 다운로드와 로컬 API 서버 배포 관리를 누구나 편리하게 제어할 수 있는 오픈소스 매니저입니다.

  • 1단계 (다운로드 및 설치): LM Studio 공식 홈페이지에 접속해 윈도우용 인스톨러를 다운로드 후 설치 실행합니다.
  • 2단계 (모델 다운로드): 좌측 돋보기 모양 메뉴(Search)에서 원하는 모델(예: Llama-3-8B-Instruct-GGUF 또는 EEVE-Korean-10.8B 등)을 검색 후 시스템 GPU 사양에 맞는 크기로 다운로드합니다.
  • 3단계 (로컬 서버 시작): 좌측 더블 화살표 모양 메뉴(Local Server)로 가셔서, 상단에서 다운로드한 AI 모델을 선택한 뒤 [Start Server] 버튼을 누릅니다. (기본 포트는 1234로 구동됩니다.)
  • 4단계 (프로그램 등록): 프로그램 AI 설정 탭에서 LM Studio (로컬 LLM)를 선택하면, 로컬 호스트(http://localhost:1234/v1)로 중계되어 무료 생성 기능이 즉각 구동됩니다.

STEP 3. 빈도/강도법 기반 위험성 평가 및 편집

선택한 항목들을 바탕으로 실제 표 형식의 편집 화면이 나타납니다. 기존의 복잡한 숫자 곱셈법에서 벗어나, 직관적인 '상·중·하' 빈도/강도법으로 쉽게 평가합니다.

주요 편집 기능

  • 내용 수정: 표 안의 '위험발생상황'이나 '감소대책' 내용이 현장과 맞지 않다면, 칸을 마우스로 클릭하여 엑셀처럼 자유롭게 글자를 수정할 수 있습니다.
  • 🪄 AI 부분 재생성 (v5.5.0 신규 ✨): 각 셀 우측의 요술봉(🪄) 버튼을 클릭하면, 사용자가 직접 수정한 상위 텍스트 정보를 자동으로 읽어 들여 해당 셀 및 하위 필드들까지 문맥에 맞게 지능적으로 자동 연쇄 재생성해 줍니다.
  • 위험성 평가 (상/중/하): 각 항목별 '현재 위험성'과 '개선 후 위험성'을 드롭다운으로 쉽게 선택하세요. (개선 후 위험성은 현재 위험성보다 높을 수 없도록 시스템이 방어합니다!)
  • 일괄 적용 기능: 상단의 일괄 적용 버튼을 누르면, 수십~수백 개의 항목을 한 번에 특정 등급(예: 중)으로 통일하거나 공통적인 감소대책 문구를 일괄 삽입할 수 있어 퇴근 시간이 획기적으로 당겨집니다.
💡 참고: 기존에 있던 엑셀 다운로드 기능은 현재 양식 최적화 및 템플릿 고도화 작업을 위해 v5.4.4 버전에서 임시 제외되었습니다. 향후 더 강력한 기능으로 재도입될 예정입니다!

보고서의 꽃, 서명 도장을 꾸며봅시다! 상단의 🖊️ 서명설정 버튼을 눌러보세요.

  1. 결재 인원 선택: 결재받을 사람이 몇 명인지(2칸~5칸) 선택합니다.
  2. 직책/성명 입력: 담당자, 소장 등의 직책과 성명을 직접 적습니다.
  3. 서명 이미지 삽입:

STEP 5. 최종 보고서 생성 및 세대별 인쇄 테마(Classic, Modern, Future) 선택

화면 맨 하단의 📄 최종 보고서 생성 버튼을 누르면, 깔끔하게 인쇄용으로 조판된 미리보기 화면이 실행됩니다. 여기서 **발주처 또는 감리단의 성향 및 눈치(?)**에 맞춰 최적의 인쇄 테마를 즉시 선택할 수 있습니다.

🖨️ 세대별/성향별 3대 인쇄 조판 테마 (v5.5.8+ 신설)

  1. Classic (기본형 꼰대 대피소 🛡️):
    가장 보수적인 형태의 폼으로, 정부 부처 산하 기관이나 까다로운 원칙주의자 감리 단체의 검수를 무난히 패스하기 위한 클래식 흑백 폼입니다. 출력 시 모든 컬러가 배제되고 깔끔한 흑백 격자 실선으로 렌더링되어 눈치 볼 필요가 전혀 없습니다.
  2. Modern (세련형 눈 보호 모드 👁️):
    가장 일반적인 민간 대기업 현장이나 세련된 디자인을 선호하는 실무자를 위해 탄생했습니다. 눈이 편안한 **슬레이트 블루(#1e3a5f) 테두리**와 가독성이 뛰어난 폰트 스케일링을 제공합니다.
  3. Future (미래지향형 진보 모드 🌌):
    MZ세대 및 한 걸음 더 나아간 진보 세대의 취향을 타겟으로 한 미래형 레이아웃입니다. 화사한 **바이올렛(#7c3aed) 및 라벤더(#c4b5fd)** 톤의 그라데이션 기조가 녹아 있어, 전통적인 서류의 패러다임을 깨는 참신한 조판 스타일을 보여줍니다.
💡 테마 적용 팁:
1) 자동 테마 복원: 선택한 인쇄 테마는 브라우저 로컬 저장소에 보존되어, 다음에 문서를 출력할 때도 이전에 골랐던 테마가 기본값으로 자동 기억됩니다.
2) 테이블 밀폐 마감: Modern 및 Future 테마의 경우 내부 격자선은 깔끔한 점선으로 가볍게 표현하면서도, 테이블의 사방 경계면(가장 우측 및 하단 선)은 테마 전용 색상의 굵은 1.5px 실선(Solid)으로 단단하게 밀폐되어 렌더링되므로 인쇄 퀄리티가 대단히 높습니다.

테마를 선택한 뒤, 우측 상단의 🖨️ 브라우저 인쇄 (PDF 저장 가능) 버튼을 눌러 종이로 출력하거나 PDF로 저장해 바로 결재에 활용하세요!

STEP 5-1. 🌐 AI 다국어 번역 및 독립 인쇄 (v5.5.21b 고도화 ✨)

외국인 근로자가 많은 현장을 위해 위험성평가서 내용을 영어, 중국어, 베트남어, 몽골어로 즉시 일괄 번역하여 출력할 수 있습니다.

  1. 번역 언어 선택: 최종 보고서 미리보기 화면 상단 액션 버튼부 우측의 🌐 다국어 번역 드롭다운에서 원하는 언어(영어/중국어/베트남어/몽골어)를 선택합니다.
  2. 번역 실행: [번역 실행] 버튼을 누르면 인공지능 안전보건 번역 엔진이 작동합니다.
  3. 실시간 진행률(%) 표시: 번역 진행 상황이 화면 전체 로딩창에 🌐 다국어 번역 중... (33%)과 같이 퍼센티지(%)로 실시간 갱신되어 진행 상태를 한눈에 파악할 수 있습니다. (3행 단위 순차 청크 번역 적용)
  4. 독립 출력 및 원본 보존: 번역본은 임시 캐시에만 보관되며, 한국어 원본 데이터는 절대 훼손되지 않습니다. 번역이 완료된 상태에서 인쇄를 누르면 번역서 그대로 깔끔하게 PDF 저장 및 인쇄가 가능합니다.
  5. 몽골어 번역 완벽 연동: 몽골어 선택 시 위험 등급 '하'가 몽골어 표준 번역어인 Бага로 올바르게 치환되며, 표지 대상명과 대분류 공종명까지 정교하게 몽골어로 번역 치환되어 출력됩니다.
